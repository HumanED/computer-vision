# Project Dependencies

This project depends on the following libraries and tools:

## Required Libraries
- [Pangolin](https://github.com/stevenlovegrove/Pangolin) - For OpenGL-based GUI and visualization
- [OpenCV 4](https://opencv.org/) - Computer vision library
- [Eigen3](http://eigen.tuxfamily.org/) - Linear algebra
- [GLEW](http://glew.sourceforge.net/) - OpenGL extension loader
- [FFmpeg](https://ffmpeg.org/) - Video processing
- [Intel RealSense SDK 2.0](https://github.com/IntelRealSense/librealsense) - For RGB-D camera support

## Build Tools
- CMake >= 3.10
- clang or any C++11 compatible compiler
- pkg-config
